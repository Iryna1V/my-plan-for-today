# About My plan for today

My plan for today it is simple Fullstack aplication, which allows users: create a plan for the day , update a tasks and delete a tasks. 

This application will help you easily and effectively plan your daily tasks.

## Functionalities:

- The app is built with advanced React concepts and hooks implementation.
- MongoDB for database, Express and Node for backend.
- Simple user interface.
- Responsive design.

## Tech stack:

- React 19.0
- MongoDB
- Node.js
- Express.js
- CSS

## Run the application:
Install dependencies:

npm install

npm i express nodemon

npm i mongoose

npm i cors

install 'axios'

set up a MongoDB database

for testing API using Postman

Start the development server:

npm run dev

Then open http://localhost:3000 to view it in your browser.

## Build for production:
To create an optimized production build, run:

npm run build

The build will be generated in the 'dist' (or 'build') folder ready for deployment.
